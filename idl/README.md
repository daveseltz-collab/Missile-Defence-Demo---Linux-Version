## DDS IDL and generated sources

`ShipThreat.idl` defines the simulation topics. The DDS-enabled build also
requires C++ type-support files generated by RTI Connext DDS; generated output is
kept in `idl/generated/` and is not committed.

On Linux, set `NDDSHOME` and run the helper from the repository root:

```bash
export NDDSHOME=/path/to/rti_connext_dds-7.7.0
./scripts/generate_rtiddsgen.sh
```

The script uses the installation selected by `RTI_CONNEXTDDS_DIR`, then
`NDDSHOME`, falling back to `PATH` only if neither is set. Use the same
installation for generation and compilation; mixing versions can cause build
or runtime errors. Rerunning the script replaces the generated type files. To
generate into a different directory, set `RTIDDSGEN_OUTPUT_DIR`. Then configure
the project with `-DUSE_CONNEXT=ON`.

The Windows equivalent is `generate_rtiddsgen.bat` in the repository root.
